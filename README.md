# MLS_LAW-FIRM

High-end, Band 1 legal chambers website and client portal.

## Overview
- **Architecture**: React (CRA) frontend, Node.js / Express backend.
- **Design System**: Noble Champagne Bronze (`#C5A059`, `#F2E3C6`), Dark Obsidian (`#0C0D11`, `#12141B`), Light Alabaster (`#FAF9F5`).
- **Features**:
  - Smooth Lenis momentum scroll & hardware-accelerated slide snapping.
  - Bespoke Chambers Preloader with authentic logo SVG mask animation.
  - Single-slide snap homepage: Hero, About Firm, Practice Areas, Testimonials, Our People, Chambers Intake.
  - Interactive Jurisprudential Treatises & Legal Intelligence Hub with live search and category taxonomy filtering.
  - Full editorial treatise viewer with sticky author credential dossier, statutory provisions sidebox, and citation copier.
  - Dark/Light dual luxury theme system.
